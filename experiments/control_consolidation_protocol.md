# 038 — Memory, inspection and steering consolidation

Registered scope, 2026-11-10, before running the consolidation checks.

## Question and scope

Can one optional API expose the already tested schema-37 path without changing
its native learning, memory or control behaviour, while supplying coherent,
detached inspection and explicit intervention boundaries?

This is engineering consolidation, not a new learning-efficacy experiment.
No fresh worlds, threshold search, policy tuning, increased memory capacity or
default promotion. Preserve all 037 manifest and completion hashes. Do not edit
the frozen implementations. Add a composition wrapper around RecallWithdrawal.

## Supported configuration

Combined weighted memory with coherent refits; local partition locks; local or
composite slow-evidence plasticity; one preserved composite predictor; explicit
recall block/release; optional fixed evidence withdrawal. Constructor policy is
fixed for the trajectory. Shadow is the new wrapper's default; existing
ContinuingLearner retains its original reference default. Current and command
policies both retain ordinary recall admission without automatic withdrawal.

Keep original capture at 384, confirmation at 448/512 and admission from 576;
make this schedule visible. Reviews remain caller-supplied. The wrapper does not
claim a general memory lifecycle. Do not combine the older explicit halving API,
temporary-plasticity closure heuristic, or other archive variants into this path.

## Contracts

Validate supported public input errors before mutation. Observation ticks are
consecutive; reviews require a current labelled observation and a nonempty valid
batch, once per tick. Configuration replaces all locks/plastic channels after a
current review, once per review. Recall commands require a labelled observation,
once per tick. Commands require reason and source; log before/after native hashes.

Observe returns pre-label deployed predictions. Inspection separately identifies
the last observed prediction and current output eligibility; neither inspection
nor diagnostic prediction refits, advances time or adds evidence. Inspection
exposes local forms, upper input dependencies, memory masses, pending decisions,
archive compatibility, active controls, costs and history. Copies are detached.

Checkpoints preserve native state and wrapper metadata, including prediction
provenance, control history and partial monitor windows. Release restores control
settings or permission, never erased evidence or previous authorization. The
wrapper is not a security boundary against code with direct object access.

## Verification declared before execution

1. Replay all 240 saved 037 trajectories through the new API, using saved
   acquisition checkpoints, worlds and command schedules. Compare every deployed
   and active prediction, native prediction event, review, configuration and
   recall command, saved inspection and final native checkpoint exactly. Include
   the existing four midway checkpoint boundaries. No newly generated labels.
2. Deterministic interaction fixtures: lock with plasticity; release without
   evidence restoration; recall incompatibility and restoration of meanings;
   block precedence over a genuinely admitting review; fresh admission after
   release; partial evidence-window checkpoint continuation; invalid-input
   rejection without mutation; detached coherent inspection and prediction.
   Synthetic fixtures establish contracts, not utility or prevalence.
3. Compare an inspected trajectory against an uninspected one through subsequent
   observations/reviews. Check current tables against pure fits from stored
   evidence. Check recall modes leave active learning equal under identical
   configurations, using the replay outputs.
4. Verify every frozen 037 dependency and completion digest before and after.

Pass requires every contract and exact replay comparison to pass. A failure
must be recorded and corrected explicitly; do not relax equality or reinterpret
it as a learning improvement. Each verification invocation saves a numbered
attempt with source hashes and logs. A 900-second ceiling per invocation bounds
execution; no rerunning older benchmark scripts that write frozen artifacts.

## Deliverables and stopping point

Architecture/API document, optional wrapper, reproducible checks, recorded
findings and navigation links. Retain experimental status for automatic
policies. Passing consolidation establishes compatibility and tested composition
contracts, not human/LLM interpretability, general steering, safety or
meta-learning. Stop before new task families or operator studies.
